# dis_ctsem

## Research Questions
1. Is there a dynamic association between stressful situations and disorganized experiences?
2. Is there a dynamic association between stressful situations and negative affect?
3. Does trait-like Disorganized Schizotypy moderate the association between stressful situations and disorganized experiences?
4. Does trait-like Disorganized Schizotypy moderate the association between stressful situations and negative affect?

## Key Variables

`esm25` = Stressful Situation (1-7)  
`esm_dis` = Disorganized Experiences (Mean)  
`esm_na` = Negative Affect (Mean)
